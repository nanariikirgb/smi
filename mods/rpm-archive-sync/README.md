# RPM Archive Sync

Клиентский мод для Minecraft Java Edition 1.20.4. Новые находки появляются в очереди модерации сайта. Одобрение записывает название, цену и редкость в существующий файл `data/community-items.json` по ключу материала и CustomModelData.

## Установка

1. Установите Java 17 и профиль Fabric Loader 0.15.11 или новее для Minecraft 1.20.4. Отдельная установка Fabric API не требуется.
2. Положите [готовый JAR](dist/rpm-archive-sync-1.0.0.jar) в папку `mods` экземпляра игры. Запустите профиль и закройте игру.
3. Откройте `config/rpm-archive-sync.json` в каталоге этого экземпляра. Укажите токен синхронизации и включите сбор. Например:

```json
{
  "enabled": true,
  "server": "play.rpmserver.com:25565",
  "endpoint": "https://smi-pearl.vercel.app/api/game-items",
  "token": "ВСТАВЬТЕ_СЮДА_СВОЙ_ТОКЕН"
}
```

4. Перезапустите Minecraft. Сверяется адрес, указанный в списке серверов, с портом (по умолчанию 25565). Для другого адреса RPM в лаунчере впишите его целиком. Для отключения задайте `"enabled": false` и перезапустите игру.

## Настройка Vercel

Подключите репозиторий к существующему проекту Vercel, корень проекта — корень репозитория. Разверните ветку с изменениями. Для рабочего сайта перенесите изменения в production-ветку и выполните deployment после настройки переменных в Settings → Environment Variables.

| Переменная | Значение |
| --- | --- |
| `RPM_ARCHIVE_TOKEN` | Отдельный секрет для модов, 32–256 печатных ASCII-символов без пробелов. Можно создать командой `openssl rand -hex 32`. Тот же секрет укажите в локальной конфигурации. |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | Существующее REST-подключение Redis с правом записи. Также поддерживаются имеющиеся в сайте пары `KV_REST_API_*` и `STORAG_KV_REST_API_*`. |
| `ADMIN_PASSWORD` | Существующий пароль админ-панели, от 16 символов. |
| `GITHUB_CONTENTS_TOKEN` | Серверный токен с доступом Contents: Read and write к nanariikirgb/smi для чтения актуальных названий и публикации одобренных предложений в main. |

В клиентский файл помещается только RPM_ARCHIVE_TOKEN. Действующая админ-панель принимает POST с origin https://smi-pearl.vercel.app. Для собственного домена обновите проверку origin в api/admin.js и адрес endpoint клиента. При тестировании отдельного развёртывания учитывайте, что действующая публикация админ-панели пишет в main.

## Проверка

1. Зайдите на настроенный сервер и откройте обычный контейнер или дождитесь обновления инвентаря с именованным кастомным предметом. Мод наблюдает за применёнными игрой обновлениями слотов. Выбираются предметы с числовым CustomModelData и оформленным буквальным названием. Простые переименования в наковальне пропускаются. Из Lore извлекаются только числовая цена и редкость из фиксированного списка.
2. Оставайтесь подключённым как минимум минуту. Откройте `/admin.html`, войдите и выберите «Предметы из игры». Мод отправляет до 32 записей за интервал. Уже названная модель и повторная находка не создают новую заявку. Для модели вне ресурс-пака доступно рассмотрение после обновления индекса.
3. Для проверки восстановления отключите доступ к сайту, оставив игру подключённой к серверу, и дождитесь обновления нового предмета. Очередь находится в папке `rpm-archive-sync` экземпляра игры, отдельно для каждой пары сервер/API. Восстановите доступ и подождите следующей минуты. Подтверждённая партия удалится из очереди. При 401 проверьте совпадение токенов и перезапустите игру после правки файла. При 503 проверьте переменные Vercel и доступ к Redis/GitHub.

## Сборка и тесты

С JDK 17 в этой папке запустите `./gradlew clean build` (Windows: `gradlew.bat clean build`). Установочный JAR появится в `build/libs/`. Из корня репозитория можно запустить интеграционные тесты командой `node --test tests/game-items.test.cjs` с Node.js 20+, redis-server и redis-cli в PATH. Тесты используют временный Redis и локальную имитацию GitHub Contents.

После замены ресурс-пака, сборок транспорта или правил исключения моделей запустите из корня `python3 scripts/build-game-model-index.py` и включите обновлённый `lib/game-model-index.json` в тот же коммит.
