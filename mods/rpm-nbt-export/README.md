# RPM Local NBT Export

Клиентский мод для Minecraft Java 1.20.4, Fabric Loader 0.15.11+ и Java 17. Установите JAR из `dist/` в папку `mods` экземпляра игры. Мод работает автономно, без токена и подключения к сайту.

После запуска в папке игры появится `rpm-nbt-export/servers.txt`. По умолчанию разрешён `play.rpmserver.com:25565`. Для другого адреса внесите его в список (по одному адресу на строку) и перезапустите Minecraft. Пустой список отключает сбор.

На разрешённом сервере мод проверяет инвентарь игрока и доступные слоты открытого контейнера каждые пять игровых тиков. Предметы с непустым NBT записываются в `rpm-nbt-export/items.json`. Сохраняется идентификатор предмета и полное дерево его тегов, включая вложенные списки и массивы. Для чисел указаны тип и точное строковое значение. Количество предметов в стопке в ключ сравнения не входит.

Одинаковая пара «идентификатор предмета + NBT» появляется в архиве один раз, в том числе после перезапуска игры. Каждое новое состояние тегов дописывается отдельной записью. Мод обновляет файл через временную копию. Перед ручной передачей файла проверьте содержимое — полный NBT может включать имена, UUID и текст книг.

Сборка с JDK 17: `./gradlew build` или `gradlew.bat build` в этой папке.
